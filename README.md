## ☕ MRV&Co

<div align="center">

`PLANNING` · `BUSINESS ANALYTICS` · `COMMERCIAL PERFORMANCE`

</div>

Projeto desenvolvido para análise de **performance comercial**, utilizando dados para construir uma visão estruturada sobre indicadores, produtividade, conversão e oportunidades de negócio.

A solução utiliza **Python e Streamlit** para transformar dados operacionais em análises, visualizações, indicadores e simulações.

### Principais análises

* Performance comercial
* Funil de conversão
* Indicadores de vendas
* Produtividade da equipe
* Análise regional
* Benchmarks
* Identificação de oportunidades
* Visualização de KPIs
* Simulação de cenários
* Geração de insights

**Stack:** `Python` `Pandas` `NumPy` `Plotly` `Streamlit`

## 🏦 Inter — Customer Analytics & Churn

<div align="center">

`CUSTOMER ANALYTICS` · `CHURN` · `BEHAVIOR` · `RETENTION`

</div>

Projeto de **Data Analytics** voltado à análise de comportamento e retenção de clientes em um contexto bancário.

A proposta é explorar os dados para compreender características associadas ao churn, identificar padrões entre diferentes perfis e encontrar oportunidades de retenção.

### Principais análises

* Perfil dos clientes
* Churn
* Comportamento transacional
* Produtos utilizados
* Canais de aquisição
* Segmentação
* Comparação entre perfis
* Identificação de padrões
* Análise comportamental
* Insights para retenção

**Stack:** `Python` `Pandas` `NumPy` `Scikit-learn` `Streamlit`
