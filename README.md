## > FEATURED_PROJECTS

### 1️⃣ MRV&Co — Planning & Business Analytics

<div align="center">

**Diagnóstico Executivo Comercial**

Uma aplicação analítica completa desenvolvida com Python e Streamlit para análise de performance comercial. O projeto transforma dados comerciais em insights estratégicos, apoiando identificação de oportunidades e benchmarks de desempenho.

**Abordagem:**
- Análise exploratória de dados comerciais
- Indicadores de performance (VSO, leads, produtividade)
- Análise por cidade com identificação de benchmarks
- Simulações de cenários comerciais
- Visualizações interativas para apresentação executiva

**Principais Achados:**
- 324 registros analisados | 258.087 leads processados
- VSO médio: 0,11% | São Luís (benchmark): 0,53% VSO
- Poá: principal oportunidade de melhoria (0,00% VSO)
- Produtividade média: 0,23% | Turnover: 0,08%

**Stack:** Python • Pandas • NumPy • Plotly • Streamlit • Scikit-learn • SciPy

**Links:**
- 🔗 [Repository](https://github.com/Carolcrypto/case-MRV)
- 🌐 [Live Demo](https://case-mrvco.streamlit.app)

</div>

### 2️⃣ Bank Churn Analysis

<div align="center">

**Identificação de Padrões de Cancelamento Bancário**

Projeto de Data Analytics focado em análise comportamental de clientes bancários. Identifica padrões associados ao churn, análise temporal de transações e sinais antecipados de risco de abandono.

**Abordagem:**
- Análise exploratória do perfil de clientes
- Comparação entre clientes ativos e que realizaram churn
- Análise temporal e comportamental
- Identificação de sinais antecipados de abandono
- Recomendações baseadas em dados para retenção

**Insights Principais:**
- Clientes em churn apresentam ~73% menos transações
- Redução de frequência de utilização é indicador forte de risco
- Análise de sazonalidade e períodos de inatividade

**Stack:** Python • Pandas • NumPy • Plotly • Matplotlib • Streamlit • Scikit-learn • SciPy

**Link:** 🔗 [Repository](https://github.com/Carolcrypto/Case-Inter)

</div>
